Private Linux x86-64, source-built static diagnostic only. This source tree is
not used to build a release, shared library or plugin. The compiler in this
tree changes only emitted literal-pool constructor calls to register their
exact relocated, immortal scalar starts separately. A normal runtime pointer
registration is not evidence that the registered object is a scalar. A
known origin alone is likewise insufficient: it needs an independently
reviewed static image, stopped-world root cut and complete old-owner cut.
Unexpected publication, raw external state or an unrecognized address deny
reclamation. No production GC3 closed-domain flag is written.

The one-shot pre-warmup image check is OFF in ordinary binaries. Integrity
of a self-normalized file alone is not proof of semantic closure or trusted
authorship. An offline reviewer must bind the specific six-module graph,
source, IR capability inventory, compiler/complete runtime, admitted origins
and actual ordered native link, reproduce the image, and qualify the exact
invocation before the separate diagnostic copy is marked. The root/foreign/
old-owner checks still apply at run time. An extension-using application must
never be admitted through an outcome in the benchmark-specific audit.

Original GC3 protocol cost experiment is compiled alongside it, preserving
managed frame roots, the tracing write barrier, real pins, and leases. This
does not specialize every body. Confirm the actual linked IR receipt, including
which GC0 fallback and guarded GC3 fast bodies were generated.

This reference old-owner cut is intentionally expensive, not the eventual
remembered-set fast path. No performance or gate claim follows from handler
completion, synthetic allocation counts, an unsealed binary, or a refused cut.
